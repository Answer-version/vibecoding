## 五、测试执行指南

### 5.1 运行单元测试

```bash
# 运行所有测试
mvn test

# 运行特定服务测试
mvn test -pl order-service
mvn test -pl user-service

# 运行特定测试类
mvn test -Dtest=CartServiceTest
```

### 5.2 运行集成测试

```bash
# 运行集成测试
mvn verify

# 生成测试报告
mvn test -DgenerateReports=true
```

### 5.3 测试报告位置

- 单元测试报告: `target/surefire-reports/`
- 集成测试报告: `target/failsafe-reports/`
